# 全球及台灣資料契約

## 全球主要經濟體

`config/economies.json` 設定 18 個觀察對象：美國、中國、日本、德國、印度、英國、法國、義大利、加拿大、巴西、韓國、澳洲、墨西哥、印尼、沙烏地阿拉伯、土耳其、南非及歐盟彙總。

World Bank Indicator API 不需要金鑰。目前每個經濟體取得實質 GDP 年增率、CPI 年增率、失業率、經常帳占 GDP、出口占 GDP、進口占 GDP、製造業增加值占 GDP、FDI 淨流入占 GDP，各取最近 5 個非空值。

這些數值是 API 目前版本，可能修訂。系統保存來源的 `lastupdated`、本機首次取得時間與明確的 `point_in_time_certified: false`，不能用今天取得的數值聲稱過去已知。

ECB Data API 不需要金鑰。系統取得 USD、GBP、JPY、CNY、CHF、CAD、AUD、KRW、INR、BRL、MXN、TRY、ZAR、IDR 對 EUR 最近 120 天參考匯率。這是官方參考值，不是盤中或可成交報價。

政策事件另由 Federal Reserve、European Central Bank 與 Bank of Japan 官方 feed 接入；feed 只負責發現，程式會再取得實際公告或 PDF，全文失敗時才明示使用 feed 摘要。這補充高頻政策事件，不代表已涵蓋所有主要央行或所有語言版本。

## 台灣最新資料

|---|---|---|---|
| 上市日行情 | TWSE `/exchangeReport/STOCK_DAY_ALL` | 每週取最近交易日全市場 | 成交值、漲跌家數、觀察公司收盤 |
| 上櫃日行情 | TPEx `/tpex_mainboard_quotes` | 每週取最近交易日全市場 | 同上 |
| 上市月營收 | TWSE `/opendata/t187ap05_L` | 每週檢查最新月份 | 全市場年增中位數、公司月營收 |
| 上櫃月營收 | TPEx `/mopsfin_t187ap05_O` | 每週檢查最新月份 | 同上 |
| 上市重大訊息 | TWSE `/opendata/t187ap04_L` | 每週取官方最新頁 | 事件查證佇列 |
| 上櫃重大訊息 | TPEx `/mopsfin_t187ap04_O` | 每週取官方最新頁 | 同上 |
| 上市估值 | TWSE `/exchangeReport/BWIBBU_ALL` | 每週取最近交易日 | PE、殖利率、PB；無有效盈餘時 PE 保持缺值 |
| 上櫃估值 | TPEx `/tpex_mainboard_peratio_analysis` | 每週取最近交易日 | 同上 |
| 上櫃三大法人 | TPEx `/tpex_3insti_daily_trading` | 每週取最近交易日 | 只顯示單日淨額；因上市覆蓋不對稱，不納入跨市場分數 |

全市場研究候選分數為營收年增橫斷面順位 40、成交額順位 20、正本益比區間 20、殖利率 10、資料完整度 10。分數只決定查證順序；月營收不等於獲利或現金流，估值也尚未依產業與景氣循環調整。

股票與公司只依官方四碼代號對應。未列入觀察名單的重大訊息仍可保存，但不猜測其上市公司 ticker。月營收金額保留為官方欄位的「新台幣仟元」，成長率不自行重算覆蓋官方值。

日行情端點在休市日可能提供最近交易日；系統使用資料內日期，不把抓取日誤當交易日。重大訊息只是公司自述事件線索，需再核對公告附件、財報與後續結果。

## 失敗、缺值與單次上限

- HTTP 失敗保留來源狀態與類型，不把錯誤訊息中的敏感內容發布。
- 缺值保持缺值，不以零或前值填補。
- 月營收及重大訊息受 `max_items_per_source` 限制時標成 `partial`；完整原始回應已封存，本機後續執行會優先處理尚未建立的觀察公司月營收。
- GitHub Pages 只使用 `public-data/v1` 的凍結精簡資料；Actions 不連官方 API，也不需要任何本機憑證。
