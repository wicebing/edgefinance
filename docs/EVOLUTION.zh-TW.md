# 持續演化

v0.3 已完成小規模研究閉環、主要經濟體比較、台灣官方市場／營收／重大訊息，以及台灣、SEC 與 Binance 公開市場研究候選雷達；以下是待辦，不是已完成功能。每週追蹤新增文件、待讀量、引用／公司匹配錯誤、候選母體變化及有用的新論點。

| 優先 | 下一項 | 驗收 |
|---|---|---|
| P0 | 真實 ODP 整週下載檔 | 件數對照官方清單，重跑去重、壞檔保留游標；目前 ZIP 解析以合成 fixture 驗證，尚未取得使用者正式下載檔 |
| P0 | 核心引文人工標註集 | 財務期間、數字、否定句、專利歸屬可核對；錯誤例加入測試 |
| P0 | 全球與台灣資料品質告警 | 交易日、發布延遲、單位、空值、資料筆數突變及 schema 變更可被測試攔下 |
| P1 | 主題分層綜合與增量檢索 | 大量文件不超單包預算，各層結論追到原文、不漏掉未讀資料 |
| P1 | 家族與公司沿革 | A1／B2 不重算獨立發明；申請／公開／核准、母子公司和收購都有時間 |
| P1 | EPO 主題、CPC、公司回補 | 取代最新批次首幾件样本；完整發現佇列、覆蓋母體 |
| P1 | 候選二階段財報與商業里程碑 | 從全市場雷達選出的候選補齊價格估值、負債、現金流、稀釋、產品／訂單證據與有效公司對應 |
| P1 | 國際交易所公司母體 | 在 SEC 外新增歐洲、日本、韓國與其他主要市場的官方上市公司與財報來源，保留幣別、會計準則與交易時區 |
| P2 | PortWatch、Comtrade、港口月報 | 處理季節、轉口、延遲、修訂；不把港口吞吐直接当公司營收 |
| P2 | IMF／OECD 與主要央行高頻資料 | 各經濟體補齊月季景氣及政策資料，保留修訂與發布時間，不把 World Bank 年資料當即時訊號 |
| P2 | 行情、公司行動、估值 | 拆股、股利、退市、幣別、稀釋正確；技術前景與股票價格分開 |
| P2 | 前瞻觀察組合與到期檢查 | 凍結當時證據、比較基準、記錄失敗和成本；樣本不足不報勝率 |
| P3 | 評估資料增益 | 新來源是否改善樣本外判斷，不以資料量代替績效 |

起始領域是運算基礎設施、能源／電網、自動化。每個候選都要問：誰付錢、何時付錢、誰取得利潤、資本及競爭門檻、股價是否已反映成長。
